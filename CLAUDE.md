# CLAUDE.md

## Commands
- Dev Server: `npm run dev`
- Build Project: `npm run build`
- Lint Code: `npm run lint`

## Code Guidelines
- Framework: Next.js App Router (using TypeScript)
- Styling: Tailwind CSS
- Design System: warm high contrast built from Graphite (#2C2C2C), Bright Brick (#EE7828), Concrete (#C5BAAA), and Craft (#806D61). Bright Brick owns actions; use Graphite text on it for contrast.
- Icons: Lucide React
- Components: Reusable components in `/components`, pages in `/app`
